## 完成内容
### Bug 修复：密码门页面首次输入被重置
**问题原因：** Gate 页面被 Next.js 静态渲染为纯 HTML，React 水合（hydration）时接管了受控输入框（`value={password}`），将用户在水合前输入的内容重置为空字符串，导致第一次点击"进入"时 `password` 为空，触发"请输入访问密码"提示。

**修改文件：** `src/app/gate/page.tsx`
- 将受控输入（`useState` + `value`/`onChange`）改为非受控输入（`useRef` + `defaultValue`）
- 密码值通过 `inputRef.current?.value` 在提交时直接读取
- React 水合不会再覆盖用户输入的内容
- 统一用 `<form onSubmit>` 处理提交

### 修复：邮箱验证邮件乱码
**问题原因：** 上次通过 API 配置邮件模板时，中文内容在传输过程中编码错误，Supabase 中存储的模板内容为乱码。

**解决方法：** 用正确的 UTF-8 编码重新设置邮件模板
