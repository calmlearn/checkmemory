- 拖拽上传 + 点击上传

- 解析进度显示
- 自动调用 AI 提取
- 错误处理和提示

### AI 提取 API (`src/app/api/extract/route.ts`)
- POST 接口接收文本
- 调用 Claude API 提取问答对

- 错误处理

### 首页 (`src/app/page.tsx`)
