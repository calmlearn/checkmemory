# 📋 项目需求文档

> 最后更新：2026-06-07

## 项目概述

一个帮助记忆知识点的网站。用户可以上传 PDF、Word、PPT 文件，网站自动提取问题和知识点，然后以随机测验的形式帮助用户记忆。

---

## 功能需求

### 1. 文件上传
- 支持 PDF (.pdf) 格式
- 支持 Word (.docx) 格式
- 支持 PPT (.pptx) 格式
- 支持拖拽上传和点击选择上传
- 显示上传进度

### 2. AI 智能提取
- 上传完成后自动解析文件内容
- 调用 AI 从文本中提取"问题-答案"对
- 显示提取进度（处理中 → 完成）
- 处理失败时给出友好提示

### 3. 题库管理
- 按文档分类展示所有问题
- 查看某个文档下的全部问题
- 删除文档及其关联问题
- 收藏/取消收藏题目

### 4. 随机测验
- 从全部题库或指定文档中随机抽题
- 每次显示一道题
- 用户可以切换显示/隐藏答案
- 记录"已掌握"或"未掌握"
- 可跳过当前题目

### 5. 学习统计
- 总正确率统计
- 每个文档的独立学习进度
- 答题历史记录
- 错题集（只显示答错的题目）
- 收藏题目列表
- 导出错题集为文本文件

### 6. UI 要求
- 简洁美观的设计风格
- 主色调为淡蓝色
- 响应式设计，支持手机和电脑访问
- 友好的空状态提示
- 直观的操作引导

---

## 非功能需求

### 数据存储
- 数据存储在浏览器本地（IndexedDB）
- 不同用户/设备的数据互不干扰
- 无需登录注册

### 性能
- 页面加载快速（静态生成）
- 文件解析在浏览器端完成，不占用服务器资源

### 部署
- 部署到 Vercel（免费）
- 通过互联网可访问
- API 密钥（Claude API）安全存储在服务端环境变量

---

## 约束条件

- 换设备或清除浏览器缓存会导致数据丢失
- 单次解析的文档大小受浏览器内存限制（建议 50MB 以内）
- AI 提取会产生少量费用（约 ¥0.1-0.5/份文档）
