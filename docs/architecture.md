## 数据流

### 上传文件流程
```
用户选择文件 → 浏览器读取文件内容（ArrayBuffer）
  → 根据文件类型选择解析器（pdf.js/mammoth/pptx）
  → 提取纯文本
  → 发送文本到 /api/extract
  → 服务端调用 Claude API 提取问答对
  → 返回结构化的 JSON 数据
  → 存入 IndexedDB（documents + questions 两张表）
  → 更新 UI 显示
```

### 测验流程
```
用户点击"开始测验"
  → 从 IndexedDB 随机取一道题
  → 显示问题文本
  → 用户可选择"显示答案"
  → 用户标记"已掌握"或"未掌握"
  → 记录存入 quizRecords 表
  → 加载下一题
```

## 技术决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 框架 | Next.js | 全栈一体，自带 API 路由，方便部署 |
| 存储 | IndexedDB (Dexie.js) | 本地存储，不需要后端数据库 |
| UI | shadcn/ui + Tailwind | 美观且可定制，淡蓝色主题容易实现 |
| 文件解析 | 浏览器端 JS 库 | 避免文件上传到服务器，节省存储成本 |
| AI API | Claude API | 提取质量高，价格合理 |
| 部署 | Vercel | 与 Next.js 无缝集成，免费额度充足 |
